# FitLens AI 食物识别评估方案

> 目标：把「识别准确」从一句口号变成可测量、可复现、注明局限的指标。**当前仓库不含任何实测数据**，本文是待执行的评估方案。

## 一、评测数据准备

1. **采集真实照片**：征集 N≥500 张（建议最终 ≥2000 张）真实用餐照片，覆盖：
   - 高频中式餐食（米饭、面食、家常菜、快餐、沙拉/轻食、水果、饮品）；
   - 不同份量（小/中/大）、不同容器（盘/碗/外卖盒）、不同光线与角度；
   - 多人份与混合菜（一道菜里多种食材）作为**困难样本**。
2. **标注（Ground Truth）**：每张图标注
   - 食物类别（大类 + 细类，双人标注，分歧交第三人仲裁）；
   - 份量（克，尽量称重或与标准容器对照）；
   - 热量与蛋白质/碳水/脂肪（由注册营养师按菜谱核算，或以可复现的换算表为准）。
3. **划分**：训练/调参集 70%、验证集 15%、测试集 15%（测试集严格 holdout，仅最终评估一次）。
4. **隐私合规**：照片采集需用户授权，去标识化，仅用于评估。

## 二、评估指标

| 指标 | 定义 | 计算 |
|---|---|---|
| **食物类别准确率 Top-1** | 首候选类别命中比例 | 命中数 / 样本数 |
| **食物类别准确率 Top-3** | 前三候选含正确类别 | 同上 |
| **份量误差 MAPE** | 估算克数与真值的平均绝对百分比误差 | `mean(|估-真|/真)` |
| **热量误差 MAPE** | 估算热量与真值误差 | `mean(|估-真|/真)` |
| **热量分档命中率** | 误差 ≤20% / ≤50% 的样本占比 | 命中数 / 样本数 |
| **营养素误差 MAPE** | 蛋白/碳水/脂肪各自误差 | 同上 |
| **用户修正率** | 识别后用户修改名称或份量的比例 | 修改样本 / 识别样本（产品侧指标） |
| **识别→保存转化率** | 识别结果最终被保存的比例 | 保存数 / 识别数 |

**报告时必须同时给出：样本量、测试条件（设备/光线/菜系分布）、以及局限**（例如「结果仅代表该评测集，不代表真实使用分布」）。

## 三、低置信度处理

- 模型输出置信度（0–1，仅表示模型自身不确定性，不等于准确率）。
- 策略：低于阈值（例如 0.6）时：
  1. 界面显著提示「结果可能不准确，请确认」；
  2. 返回 **Top-k 候选**让用户点选，而不是只给一个默认值；
  3. 份量默认给「可修正」的中位档，并在说明中标注「份量为估算」。
- 阈值通过验证集校准：在「减少用户误保存」与「减少用户额外操作」之间取平衡。

## 四、用户修正机制（产品侧）

- 识别结果进入可编辑表单：名称、份量、餐次、热量、营养素均可改。
- 份量调整按每 100g 营养值**等比换算**，减少重复输入。
- 修正后的数据回流：在用户授权下，把「修正后结果 + 原图」作为**弱监督样本**进入下一轮训练/微调，并做数据质量抽检。
- 用「修正率」反向度量模型与用户预期的差距，指导迭代方向。

## 五、验收口径（诚实原则）

- 不发布没有样本量与测试条件支撑的准确率。
- 不把「模型置信度」表述成「准确率」。
- Demo 中的模拟识别**不产生任何可引用指标**。
