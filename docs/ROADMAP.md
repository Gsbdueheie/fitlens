# FitLens 迭代路线

## 短期（MVP 后 1–2 个迭代周期）

- **接入真实多模态识别**：自建后端代理 → 接入视觉模型，保留 `mock` 作为降级兜底。
- **真实账号系统**：手机号短信验证 + 后端账号 + 云端数据同步（多设备）。
- **食物数据库与搜索**：高频食物库（含中式家常菜），手动记录支持搜索补全。
- **识别置信度 UI 细化**：Top-k 候选、低置信度强提示、份量档位选择。
- **补充评测集与首轮实测**：按 `AI_EVALUATION.md` 跑第一轮，发布带样本量与局限的实测结果。
- **动效/空态打磨**：加载、成功、失败、表单校验等状态补全，提升演示质感。

## 中期（3–6 个月）

- **修正数据回流训练**：合规采集「原图 + 修正结果」做弱监督微调。
- **更智能的每日目标**：结合身高/体重/年龄/目标动态估算 TDEE，替代固定默认值。
- **训练计划与提醒**：打卡提醒、周训练概览、目标达成激励。
- **身体数据趋势洞察**：体重变化速率、围度变化关联（不提供医疗诊断，只做趋势提示）。
- **多语言准备**：保持中文优先，预留 i18n 结构。

## 边界声明

- 不提供医疗/疾病诊断，不给极端减重建议。
- 不把模型估算包装成精确测量，持续用评测指标而非宣传话术验证能力。
