# FitLens 产品指标建议

## 北极星指标（NSM）

**每周「有效记录日」数**（有 ≥1 条饮食记录 且 ≥1 条训练或身体数据的天数）。
它同时反映「记录习惯的建立」与「多模块联动」，比单一记录数更能代表产品核心价值。

## 关键指标

| 指标 | 定义 | 含义 / 为什么重要 |
|---|---|---|
| **周活跃用户（WAU）** | 7 天内打开并产生任一记录的用户数 | 基础规模与活跃度 |
| **饮食记录完成率** | 有记录的天数 / 活跃天数 | 核心习惯是否建立，直接影响热量总览可用性 |
| **训练打卡留存（D7 / D30）** | 首次打卡后第 7 / 30 天仍打卡的用户占比 | 训练模块的长期价值 |
| **识别后修改率** | 识别记录中被修改名称/份量的比例 | 反映 AI 结果与用户期望的差距，越低体验越好（但过低需警惕用户「懒得改直接存」） |
| **识别→保存转化率** | 识别结果最终保存的比例 | 识别流程是否顺畅、结果是否被信任 |
| **每日总览访问率** | 活跃日中访问首页的比例 | 汇总价值是否被感知 |
| **热量预算命中率** | 摄入落在目标 ±10% 内的天数占比 | 记录是否真正帮助用户控制 |

## 建议观测口径

- **饮食记录完成率**：`记录天数 / 活跃天数`，按月/周统计。
- **识别后修改率**：`有修改的识别记录 / 识别记录总数`；细分「改名称」「改份量」两类。
- **训练打卡留存**：用队列分析（cohort），按首次打卡周分组看留存曲线。

## 目标设定（示例，需上线后用真实数据校准）

- WAU 环比 ≥ +5%；
- 饮食记录完成率 ≥ 60%；
- 训练打卡 D30 留存 ≥ 25%；
- 识别→保存转化率 ≥ 70%；
- 识别后修改率 ≤ 30%（配合准确率指标联合判断）。

## 与 AI 指标的联动

- 若「修改率」高而「热量误差」也高 → 优先提升模型能力；
- 若「修改率」高但「热量误差」低 → 问题可能在交互（默认份量/候选），优化产品而非模型。
